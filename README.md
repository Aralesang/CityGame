# 自主世界冒险 RPG：第一个可玩闭环

目标是简化版《矮人要塞》冒险模式：玩家控制一个角色进入自主运转的世界，小镇与经济是世界的一部分。当前提供命令行格子地图，尚无图形引擎、战斗或存档。

## 开始冒险

运行 `npm start`，在交互终端中从第一天 07:00 的自家床铺醒来。按键立即生效，画面原地刷新，无需回车：

- 方向键或 WASD：移动。
- E / R：在仓库取面包 / 饮水。
- 1 / 2：吃面包 / 喝水。
- 空格：等待一小时；Z：在自家床铺上睡到早晨。
- Q、Esc 或 Ctrl+C：退出（暂不保存）。

屏幕采用左右分栏：左侧为地图与图例，右侧用框线分隔时间位置、角色状态、背包与公共物资、附近居民、操作提示及近期消息。窗口缩放时重新布局，中文按显示宽度对齐，消息自动折行。至少需要 64 列、26 行，推荐 80 列、30 行；窗口过小时显示放大提示。退出会恢复光标和原来的终端画面。不操作时世界暂停，每次有效行动仍推进一小时。

想体验第一个闭环：右 → 下（出门）→ 右 → 右（仓库）→ E → 1 → 左 → 左（进家门）→ 左（床铺）→ Z。

## 可进入的房屋

玩家住所和四间 NPC 民居各有一张独立室内地图。室外 `H` / `h` 代表门口，走上门口会自动进入房屋；室内走上 `D` 出口会回到对应门外，不需要额外按键。墙壁 `#` 和桌椅 `t` / `c` 无法穿过，床铺 `b` 可以站上去。只有自己的床铺允许按 Z 睡觉，站在门外或别人家的床上都不行。

左侧地图会自动切换室内/小镇，标题、图例和右侧位置同步更新，附近居民仅显示同一空间中的 NPC。可以进入他人民居，暂未实现锁门和所有权限制。NPC 使用与玩家相同的房门连接和移动规则，寻路出门工作、回到自家床铺休息；走路不计为生产，回床途中不恢复睡眠疲劳。房间通过 `mapId` 隔离，内部同坐标不会混淆。

原有逐行命令模式通过 `npm start -- --commands` 启动；重定向输入或输出时也会自动使用此模式。以下是逐行命令示例（每行回车）：

```text
e
s
e
e
look
take bread
status
use bread
w
w
w
sleep
history
quit
```

`n/s/e/w` 移动；`look` 看地图、附近居民及当前地点；`status` 看位置、需求和背包；`take bread` / `take water` 在公共仓库取一份物资；`use bread` / `use water` 消耗背包物资；`wait 8` 等待八小时（1～168）；`sleep` 在住所睡到下一次早晨六点；`help` 查看帮助。

地图符号：`@` 玩家、`N` NPC、`H/h` 房门、`D` 室内出口、`b` 床、`t/c` 桌椅、`S` 公共仓库、`F` 农田、`B` 面包坊、`W` 水井、`^` 可通行野外、`#` 墙壁或边界。多个角色可以同格，玩家符号会覆盖居民符号，附近列表仍显示居民。

一次移动、拿取或使用耗时一小时；观察和失败行动不耗时。玩家与 NPC 共用移动、需求变化规则。NPC 每小时沿包含房门连接的最短路径走一格，抵达后的工作小时才产生商品。玩家没有输入时世界暂停，等待/睡眠会连续推进世界。室内通勤也计入时间，因此 NPC 的实际产出比只有室外图标时更少。

公共仓库直接对应经济库存，免费取用物资会减少后续可用供应并影响午夜调价。玩家需手动进食饮水，NPC 暂沿用每日自动购买；没有所有权、负重、地面散落物、饥渴伤害或死亡。需求封顶 100。目前生产仍是午夜统一入库，画面上的“工作”代表累计出勤，不是即时产出。

新增结构：`src/data/map.js` 地图与逻辑地点；`src/simulation/actors.js` 共用角色规则；`src/simulation/adventure.js` 创建冒险、提交行动和观察；`src/cli.js` 交互终端。`act(world, action)` 返回行动结果及跨日结算报告，`observe(world)` 返回地图与附近居民数据。近期行动记录最多保留 100 条；未来可替换终端表现层而保留模拟核心。

## 原有批量模拟

Node.js >=22，原生 JavaScript ES modules，无外部依赖，无画面引擎。

```powershell
npm run simulate
npm run simulate -- 30
npm test
```

默认观察 7 天，每天输出生产、需求、实际消耗、缺口、剩余库存与次日价格。支持 1～10000 天。

## 结构与调用

- `src/data/town.js`：固定的 4 位居民、3 个职业、3 种商品及配方。
- `src/simulation/world.js`：独立世界状态、小时推进、午夜结算与快照，无终端或引擎依赖。
- `src/simulate.js`：原有批量模拟入口（无空间移动，保持第一阶段行为）。
- `test/world.test.js`：时间边界、产业短缺、资金限制及长期守恒测试。

```js
import { createWorld, advanceHours, snapshot } from './src/simulation/world.js';
const world = createWorld();
advanceHours(world, 8); // 第一天 08:00，可读取 NPC activity/location
const reports = advanceHours(world, 16); // 午夜完成一次结算，进入第二天
const state = snapshot(world); // 独立、可序列化的数据副本
```

每个世界单独持有状态。一次推进多个小时与逐小时推进结果一致。核心没有真实时间计时器，未来画面层可以按游戏速度调用同一入口；玩家睡觉也只需推进至下一天。

## 当前规则

一天 24 小时，从第一天 00:00 开始。06:00 前、22:00 后睡觉；工作时间采用左闭右开区间。性格通过预设工作时段体现，不设通用性格 AI。饥饿/口渴每小时分别增加 2/3，范围 0～100；任一达到 80 时留在家中休息，暂停工作。疲劳为观察数值，睡觉每小时恢复 8，醒着增加 3，暂不影响决策。

午夜依次执行：

1. 按累计有效工作小时结算生产，先生产小麦、饮水，再加工面包；缺少原料时减少实际产出和工资。
2. 外部雇主按实际生产小时发薪，每小时 2 金币。
3. NPC 根据饥饿/口渴购买面包和水，每单位恢复 25 点；不足一个单位的需求留到次日。受库存、现价和金钱限制，每天轮换购买顺序。
4. 更新价格并返回当日报告，重置工作小时，再进入次日。白天价格保持不变。

价格公式：`基础价 × clamp(1 + 0.5 × (目标库存 - 剩余库存 + 未满足需求) / 目标库存, 0.5, 3)`，保留两位小数。需求包含加工投入与居民购买意愿，缺口包含缺货及买不起的部分。报告满足 `期末库存 = 期初库存 + 生产 - 实际消耗`。

## 原型边界

市场为公共库存；购买款流出模拟、工资来自外部，不是封闭经济。没有个人囤货、生产成本核算、腐败损耗、死亡、随机事件、关系、移动寻路或玩家。地点仅是逻辑标识，睡眠和休息不触发额外消费，所有物资消费统一在午夜执行。长期过剩会积累库存、价格触及下限；这是当前规则的可观察结果，还没有库存容量和生产调节。

后续优先围绕角色冒险扩展：地面物品与所有权、交互、探索风险及简单战斗；继续让这些行动通过世界状态产生实际影响。
