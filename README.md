# 自主世界冒险 RPG：第一个可玩闭环

目标是简化版《矮人要塞》冒险模式：玩家控制一个角色进入自主运转的世界，小镇与经济是世界的一部分。当前提供命令行格子地图，尚无图形引擎、战斗或存档。

## 开始冒险

运行 `npm start`，方向键移动，Z 是唯一交互键，无需回车。Q 退出游戏；Esc 关闭物品界面，在地图上按 Esc 则退出。暂不保存。

- 自家床铺 b 上按 Z：睡到下一次早晨六点；其他人的床不能睡。
- 地面物品 ! 上按 Z：拾取整堆物品到背包。开局床左侧有一份面包可试用。
- 公共箱子 C 上按 Z：打开箱子。←/→ 切换左侧箱子与右侧背包，↑/↓ 选择物品，Z 每次拿取或存入一份，Esc 返回地图。
- 空地上按 Z：打开背包，↑/↓ 选择，Z 使用食物或饮水，Esc 返回。

已移除 WASD、E/R、1/2 和空格的快捷操作。箱子会显示全部实际有库存的物品，包括小麦。小麦暂不可直接食用。拿空一栏后会显示“空”，可以切换另一栏继续操作。

打开界面、浏览和失败操作不耗时。移动、拾取、使用、实际转移物品耗时一小时，世界与 NPC 同步推进。箱子存储与经济市场共用同一份实际库存，NPC 生产入箱、每日购买从箱中扣除，存取会影响次日供应和价格。

初次体验：左 → Z（拾取面包）→ Z（打开背包）→ Z（吃面包）→ Esc → 右（回床）→ Z（睡觉）。去箱子：从床向右、向下出门，再向右两格，按 Z 打开。

屏幕采用左右分栏，进入物品界面时显示左右物品栏。至少需要 64 列、26 行，推荐 80 列、30 行。窗口缩放会重新布局；退出恢复终端画面。重定向输入/输出或使用 `npm start -- --commands` 时进入逐行兼容模式，输入 up/down/left/right、z、escape、q 后回车，操作语义一致。

## 可进入的房屋

玩家与四位 NPC 各有独立室内空间。走上室外 H/h 房门自动进入，室内走上 D 自动离开，门不需要额外交互。墙壁 # 和桌椅 t/c 阻挡移动，床铺 b 可站立。图例、房屋名称和附近居民随空间切换。NPC 通过同一套移动与房门规则寻路工作、回床休息，通勤不计入生产。暂未实现锁门、所有权、战斗、死亡和存档；NPC 仍按每日结算购买生活物资。

## 原有批量模拟

Node.js >=22，原生 JavaScript ES modules，无外部依赖，无画面引擎。

```powershell
npm run simulate
npm run simulate -- 30
npm test
```

默认观察 7 天，每天输出生产、需求、实际消耗、缺口、剩余库存与次日价格。支持 1～10000 天。

## 结构与调用

- `src/data/town.js`：固定的 4 位居民、3 个职业、3 种商品及配方。
- `src/simulation/world.js`：独立世界状态、小时推进、午夜结算与快照，无终端或引擎依赖。
- `src/simulate.js`：原有批量模拟入口（无空间移动，保持第一阶段行为）。
- `test/world.test.js`：时间边界、产业短缺、资金限制及长期守恒测试。

```js
import { createWorld, advanceHours, snapshot } from './src/simulation/world.js';
const world = createWorld();
advanceHours(world, 8); // 第一天 08:00，可读取 NPC activity/location
const reports = advanceHours(world, 16); // 午夜完成一次结算，进入第二天
const state = snapshot(world); // 独立、可序列化的数据副本
```

每个世界单独持有状态。一次推进多个小时与逐小时推进结果一致。核心没有真实时间计时器，未来画面层可以按游戏速度调用同一入口；玩家睡觉也只需推进至下一天。

## 当前规则

一天 24 小时，从第一天 00:00 开始。06:00 前、22:00 后睡觉；工作时间采用左闭右开区间。性格通过预设工作时段体现，不设通用性格 AI。饥饿/口渴每小时分别增加 2/3，范围 0～100；任一达到 80 时留在家中休息，暂停工作。疲劳为观察数值，睡觉每小时恢复 8，醒着增加 3，暂不影响决策。

午夜依次执行：

1. 按累计有效工作小时结算生产，先生产小麦、饮水，再加工面包；缺少原料时减少实际产出和工资。
2. 外部雇主按实际生产小时发薪，每小时 2 金币。
3. NPC 根据饥饿/口渴购买面包和水，每单位恢复 25 点；不足一个单位的需求留到次日。受库存、现价和金钱限制，每天轮换购买顺序。
4. 更新价格并返回当日报告，重置工作小时，再进入次日。白天价格保持不变。

价格公式：`基础价 × clamp(1 + 0.5 × (目标库存 - 剩余库存 + 未满足需求) / 目标库存, 0.5, 3)`，保留两位小数。需求包含加工投入与居民购买意愿，缺口包含缺货及买不起的部分。报告满足 `期末库存 = 期初库存 + 生产 - 实际消耗`。

## 原型边界

市场为公共库存；购买款流出模拟、工资来自外部，不是封闭经济。没有个人囤货、生产成本核算、腐败损耗、死亡、随机事件、关系、移动寻路或玩家。地点仅是逻辑标识，睡眠和休息不触发额外消费，所有物资消费统一在午夜执行。长期过剩会积累库存、价格触及下限；这是当前规则的可观察结果，还没有库存容量和生产调节。

后续优先围绕角色冒险扩展：地面物品与所有权、交互、探索风险及简单战斗；继续让这些行动通过世界状态产生实际影响。
