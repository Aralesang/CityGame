# 自主小镇冒险 RPG

TypeScript 终端格子游戏：玩家在小镇与森林中探索，NPC 自动工作、生产、存货、买卖和进食。默认行动模式，玩家不操作时世界不推进；按 T 可开启自动模式，每 2 秒推进一个游戏小时。

## 运行

需要 Node.js >=22。

```sh
npm install
npm start
npm run build      # 仅编译，不启动游戏或执行测试
npm run typecheck  # 仅类型检查
npm run simulate -- 7  # 开发者主动运行时，观察七天社会状态
```

当前约定由开发者手动测试，修改后只确认编译。全屏界面至少 64 列 × 26 行，推荐 80 列 × 30 行。重定向输入输出或 `npm start -- --commands` 使用逐行命令模式，输入 w/a/s/d、up/down/left/right、e、f、b、space、.、m、t、q 后回车。

## 操作

| 按键 | 功能 |
| --- | --- |
| W/A/S/D | 移动并改变朝向，成功移动耗时一小时 |
| 方向键 | 原地转向，不耗时 |
| . | 选择脚下 ○，不耗时 |
| E | 检查当前目标，相邻一格或脚下，不耗时 |
| F | 与 NPC 选择对话/交易、打开容器、拾取物品、在自己床上睡觉 |
| B | 独立打开背包 |
| 空格 | 原地等待一小时，保持朝向 |
| Q | 关闭当前界面，地图上无操作 |
| T | 在任意界面切换自动／行动推进模式 |
| M | 打开或关闭地图，按真实位置显示对象名称 |
| Ctrl+C | 结束进程并恢复终端 |

自动模式由真实时钟独立推进世界，移动、拾取、使用、存取和交易不会额外跳时间，每个时段最多执行一次有效实际行动。原地转向、检查、浏览和关闭界面不占行动次数；打开任何菜单都不会暂停世界。

自动模式睡眠持续到下次六点，可按空格提前醒来。空格等待不会快进世界。玩家死亡后 NPC 社会仍继续运行。人物走开、店员离岗或关店时，相关交互和交易菜单会更新或关闭，避免继续远程操作。

行动模式保留原行为：有效实际行动推进一小时，睡眠快进至下次六点；打开、浏览、关闭界面和失败操作不推进时间。T 切换模式不推进时间，若正在自动睡眠会唤醒玩家。

速度在 `src/config/game.json` 配置：

```json
"clock": {
  "automatic": false,
  "intervalMs": 2000
}
```

intervalMs 是每推进一小时所需的真实毫秒数，至少 100。修改后重新启动生效。程序退出或逐行输入流关闭时清理计时器；不对程序关闭期间补算离线时间。

## 生存与个人物资

饱腹和水分的 100 表示充足，逐小时分别减少 2、3；任一归零开始扣血，两者同时归零时伤害叠加。当前缺粮每小时扣 5 生命，缺水扣 8。玩家与 NPC 共用同一套规则。生命归零后停止该生物的行动、生产和交易；不自动复活，自动模式世界仍继续运行。

每份面包恢复 25 饱腹，饮水恢复 25 水分，不能超过 100。玩家在背包中选物品按 F 使用；NPC 会按阈值自动消耗随身物资。疲劳另行计算，睡到床上才有睡眠恢复，疲劳暂不影响生产。

小镇公共仓库已经移除。每个 NPC 都有独立的随身库存、金币和自家箱子；初始物资分别在 npcs.inventory 与地图中家用 C 的 contents 配置。回家时 NPC 到箱子附近补货，下班后将超过携带目标的物品存回。

C 是通用容器，所有箱子都独立持有库存。NPC 箱子通过 ownerId 标注主人，玩家不能直接拿取他人物资；无主人箱子或玩家自家箱子可正常存取。自己的箱子在住所 `(3,2)`。

## 生产与金币交易

农夫产小麦，面包师消耗小麦制作面包，挑水工生产饮水。生产每小时执行一次，须到达工位附近、有足够原料且未达到库存目标；产出进入生产者随身库存。**没有工资，没有系统买单，金币不因生产或时间推进而产生。**

每名 NPC 配置初始金币，玩家也有初始金币。当前配置每人 60 金币，四名 NPC 加玩家共 300。每笔交易都同步扣买家金币、增加卖家金币，并转移实际商品；钱或货不够就失败。玩家金币也参与同一守恒统计；死亡不会删除遗留金币和物资。

M 是带商店属性的房屋，走上房门进入。店主按售货日程到室内柜台工作，实际在岗时才营业：

| 位置（小镇） | 店主 | 出售 |
| --- | --- | --- |
| (8,6) | 阿林（12～21 点） | 小麦 |
| (12,6) | 阿秋（15～21 点） | 小麦 |
| (7,8) | 小麦／面包师（13～21 点） | 面包 |
| (19,9) | 阿河（12～21 点） | 饮水 |

进入店内后，面向相邻店员按 F，选择“对话”或“交易”。店员不在岗时仍能正常对话，但不提供交易。交易界面 ←/→ 切换购买和出售，↑/↓ 选择，F 每次交易一份，Q 返回。

每家店内有独立货箱，商品列表就是货箱里的所有实际物品。买入从货箱扣货，卖出放入货箱；金币在玩家/买家与店员之间转移，不能直接免费打开其他 NPC 的货箱。stockGoods 只决定店员优先搬运什么，不限制箱中其他商品的销售。

NPC 必须亲自到货箱旁补货，把随身成品搬入箱子，或从家中取货再运来。店主离开柜台、搬运、采购、休息或死亡时停止营业，不存在无人代售。生产和售货分时安排；当前每小时生产配置为农夫两份小麦、面包师用两份小麦制作四份面包、挑水工六份饮水，仍需要投入实际原料并受负重限制。

## 重量与搬运

道具的 weight 定义单件重量，玩家 maxCarryWeight 默认为 20，NPC 为 32。角色状态和背包界面显示当前/最大负重，E 检查 NPC 也能看到其负重。

- 拾取、从箱子取物、购买都检查负重；不能容纳的物品不会进入背包或被扣款。
- 地面堆叠只拾取装得下的部分，剩余物品留在原地。
- NPC 生产先计算消耗原料后的产出重量，超重则不生产；取货、采购也按剩余容量限量。
- NPC 负重接近上限（80%）时优先搬运到家用箱子或店铺货箱，再继续工作；配置携带目标须低于这一阈值，避免反复取出又存入。
- 当前只限制随身物品重量，金币不计重，箱子没有容量上限。

现阶段按 items.basePrice 使用固定整数金币价格：小麦 12、面包 9、饮水 2。物资可以通过生产增加，金币只在角色之间流转。长期供需与个体财富分配仍需手动运行确认，不会通过补发金币或补货强行保证 NPC 存活。

## 文字地图与视野

小镇扩大为 25×15，住宅、店铺与工位有更多间距。主界面的字符地图会根据终端可用区域跟随玩家滚动，并显示当前视野的坐标范围；世界坐标不会因视野滚动而改变。

按 M 打开空间地图：保留实际地图的坐标布局和地形轮廓，将房屋、店铺、工位、容器、家具、树木、路牌、NPC 和地面物品直接标注为名称。每个原始格子对应固定大小的文字区域，较长名称在本格换行；同格对象合并显示，【你】标记玩家位置。顶部与边缘显示坐标，上北下南、左西右东。进入房屋后只显示当前室内地图。

方向键平移地图，PgUp/PgDn 纵向翻页，Home 回到玩家位置，End 移至地图末端，M 或 Q 关闭。地图可从其他界面打开，关闭后返回原界面；查看地图不移动或消耗玩家行动。若主动开启自动模式，地图打开时世界仍继续运行，人物位置会实时刷新。

## 地图与配置

小镇 `(24,8)` 的 > 进入森林，森林 `(0,4)` 的 < 返回。森林有树木、路牌、可进入的小屋及两份可拾取饮水。不同地图角色与对象互相隔离，切图不重建世界。

配置使用 `src/config/tiles.json` 部件模板、`maps.json` 字符布局与坐标 overrides。运行时创建地图实例 UUID，配置引用使用地图与坐标；目前没有存档。道具、职业、NPC、地图、初始状态及规则的详细字段见 [配置说明](src/config/README.md)。修改 JSON 后重新运行 `npm start` 生效。

## 代码结构

- `src/data/config.ts`：JSON 加载、引用及数值校验。
- `src/data/map.ts`：模板/覆盖展开、实例 UUID 和坐标索引。
- `src/simulation/actors.ts`：跨地图移动、碰撞、寻路、通用生存及道具使用。
- `src/simulation/economy.ts`：私有库存、交易、生产、金币和物资统计。
- `src/simulation/world.ts`：NPC 计划、移动、采购、逐小时推进和日报。
- `src/simulation/adventure.ts`：玩家行动、交谈、店铺和容器交互。
- `src/map-directory.ts`：地图对象的空间名称标注。
- `src/world-clock.ts`：真实计时、自动日报与失效菜单同步。
- `src/controls.ts`、`src/terminal-layout.ts`：输入与终端排版。

world.market 仅为全社会物资总量的派生统计，不是公共库存。生产和食用进入当日账本，交易与存取不改变社会物资总量；午夜汇总报告，不集中发薪或集中购买。日报含社会金币与初始金币，逐小时代码还会检查金币总量是否发生变化。
